# Spendwise - Budget Tracker

A simple dashboard to track income and expenses in one place. Built with HTML, CSS, and JavaScript.

Monthly budget: **Ksh 45,000**

## Features

- Add and delete expenses
- Auto-updates Total Spent, Remaining, and Progress Bar
- Category cards show spent vs budget (Food, Rent, Transport, Entertainment, Savings, Utilities)
- Financial tips section
- Dark mode + mobile responsive

## Files

**`index.html`** - Structure
Sidebar, header, summary cards, category cards, add-expense form, and expenses table.

**`style.css`** - Styling
Layout with CSS Grid + Flexbox, colors with CSS variables, hover/focus animations, responsive design, and dark theme.

**`index.js`** - Logic
Adds/deletes expenses, calculates totals, updates progress bar and category cards.

## How to Run

1. Download this repo
2. Open `index.html` in your browser
3. Add an expense and watch the totals update
